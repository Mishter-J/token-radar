How implied value is computed

One function of the snapshot’s own figures scores every row. No protocol name is special-cased, and no row is hand-picked.

implied = SCALE × ln(1 + TVL / $1M) × growth × maturity

Value saturates with size. The house model multiplies TVL linearly, so a protocol with 100× the TVL gets 100× the implied value. Traded protocols do not behave that way, so this radar takes the logarithm: doubling TVL from $50M to $100M adds the same implied value as doubling from $1B to $2B. SCALE is not a guess — it is the median of mcap / (ln(1 + TVL / $1M) × growth × maturity) over the snapshot’s own traded protocols, fitted at runtime (about $3.7M per log unit on this snapshot).

Growth is 1 + clamp(change_7d, −50, +150) / 100 × 0.5. Maturity is 0.60 + min(age_days, 1095) / 1095 × 0.40; a protocol whose listing date is unknown counts as 365 days old. Age is the time since first listing — the best record of how long a protocol has run with no token.

Backtest: what the model gets right, and what it does not

Tested on the snapshot’s 89 traded protocols (tvl > 0, mcap > 0, disguised categories and versioned names excluded). Median absolute log error: house model 1.495, the previous entry 1.486, this model 1.154. Predictions within 2× of the real market cap: 34.8% (house 31.5%). Within 5×: 64.0% (house 53.9%). Category multiples were tried — arithmetic and log-space, shrunk toward the global median — and both made the error worse (1.625 and 1.617), so they are not in this model: at 1–15 samples per category the category signal is noise.

The honest limit: the model under-predicts the largest traded tokens — their market caps run ahead of TVL on speculation the snapshot cannot see. It is calibrated for the board’s own universe (pre-token protocols), where it beats the house on every metric. It does not claim to price the largest traded tokens, and the board ranks pre-token protocols, not traded ones.

How to read the board

Watchlist rows carry the watchlist badge; early rows are the 160 best rankable pre-token protocols below the $50M floor. Disguised categories (centralised exchanges, bridges, liquid staking) are excluded: their TVL hides a token behind a different product. Names ending in a version number are excluded as rebrands, not launches. Live-token protocols are set aside in their own table with their real market caps — a fact, not a model.
